# Dungeons n Dudes

**Dungeons n Dudes** to projekt, w ramach którego chcemy umożliwić wszystkim fanom gier typu [Dungeons & Dragons](https://en.wikipedia.org/wiki/Dungeons_%26_Dragons) łatwiejsze skupienie się na tym, co w tych grach jest najważniejsze -- przejmując od nich żmudne i monotonne obowiązki śledzenia złożonego stanu gry. Chcemy też wprowadzić różnorodne udogodnienia pozwalające wysunąć 🍗 na pierwszy plan.
