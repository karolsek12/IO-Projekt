# Słownik domenowy

Słownik domenowy (Domain Glossary) definiuje pojęcia używane w projekcie, aby wszyscy członkowie zespołu rozumieli je w ten sam sposób.

Pojęcia opisujemy językiem dziedziny, dla której tworzymy system, a nie językiem technologii.

## Pojęcia

| Pojęcie | Definicja |
| --- | --- |
| Gracz | Osoba uczestnicząca w grze, niebędąca mistrzem gry. |
| Mistrz gry (game master) | Osoba prowadząca sesję gry. |
| RPG | System rozgrywki w grę wyobraźni (z ang. role-playing game), w którym biorą udział gracze wcielający się w fikcyjne postaci. |
| Lobby | Wirtualny zespół agregujący graczy, mistrza gry oraz stan gry. |
| Sesja | Ciąg rozgrywek w ramach jednej kampanii. |
| Stan gry | Zbiór informacji zapisywany po zakończeniu rozgrywki na temat postaci, przedmiotów i umiejętności (w zależności od konkretnej gry).|
| Statystyki | Wartości opisujące postać gracza rozpoznawane przez system gry, w który grają gracze oraz mistrz gry.  |
| Notatki (logi) | Informacja na temat minionej rozgrywki zapisana przez mistrza gry lub dowolnego z graczy. |
