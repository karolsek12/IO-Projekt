# UC-04: Zarządzaj własną postacią (Wgranie / Edycja)

## Aktor  

Gracz

## Wymagania  

FR-03, FR-05, NFR-01

## Warunek wstępny  

Gracz dołączył do danego lobby

## Cel  

Karta postaci i statystyki zostają zapisane w lobby.
Widoczne wyłącznie dla Gracza i Mistrza Gry

## Główny scenariusz

1. Gracz przechodzi do widoku swojej postaci w wybranym lobby.
2. Gracz wybiera opcję wgrania nowej karty postaci lub
edycji stanu gry opisującego gracza.
3. Gracz wprowadza zmiany.
4. System zapisuje zmiany i aktualizuje stan gry.
