# UC-07: Dodaj notatkę do rozgrywki

## Aktorzy  

Gracz, Mistrz Gry

## Wymagania  

FR-07

## Warunek wstępny  

Użytkownik jest członkiem lobby

## Cel  

Nowa notatka zostaje trwale zapisana

## Główny scenariusz

1. Użytkownik przechodzi do widoku notatek danej sesji.
2. Użytkownik wybiera akcję „Dodaj notatkę”.
3. Użytkownik wprowadza treść notatki.
4. Użytkownik zatwierdza wpis.
5. System zapisuje notatkę i aktualizuje widok notatek rozgrywki.
