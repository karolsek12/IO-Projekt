# UC-03: Dołącz do lobby

## Aktor

Gracz

## Wymagania

FR-01

## Warunek wstępny

Użytkownik jest zalogowany oraz posiada kod zaproszenia od Mistrza Gry

## Cel

Gracz dołącza do lobby

## Główny scenariusz

1. Gracz wybiera opcję „Dołącz do lobby”.
2. Gracz wprowadza kod zaproszenia.
3. System weryfikuje poprawność kodu.
4. System dodaje Gracza do wskazanego lobby z rolą gracza.
5. System wyświetla widok sesji.

## Scenariusze alternatywne

## 3a. Kod nieprawidłowy lub nieistniejący

  1. System informuje o nieprawidłowym kodzie.
  2. Gracz ma możliwość ponownego wprowadzenia kodu.
