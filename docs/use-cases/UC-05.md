# UC-05: Przeglądaj statystyki wszystkich graczy

## Aktor  

Mistrz Gry

## Wymagania  

FR-02, NFR-01

## Warunek wstępny  

Mistrz Gry znajduje się w swoim lobby,
do którego przypisane są gracze z kartami postaci

## Cel  

Mistrz Gry ma wgląd w aktualny stan postaci wszystkich uczestników

## Główny scenariusz

1. Mistrz Gry otwiera panel zarządzania sesją/lobby.
2. System wyświetla zagregowaną listę wszystkich dołączonych graczy.
3. Mistrz Gry wybiera dowolną postać, aby wyświetlić jej statystyki.
