# UC-01: Zaloguj się

## Aktor

Użytkownik

## Wymagania

FR-06, NFR-01

## Warunek wstępny

Użytkownik nie jest zalogowany.

## Cel

Zalogowanie się przez użytkownika.

## Główny scenariusz

1. Użytkownik otwiera formularz logowania.
2. Użytkownik podaje login oraz hasło.
3. System weryfikuje poprawność danych uwierzytelniających.
4. System loguje użytkownika i wyświetla informacje o lobby użytkownika.

 Scenariusze alternatywne:

## 3a. Błędny login lub hasło

1. System wyświetla komunikat o błędnych danych.
2. Powrót do kroku 2.
